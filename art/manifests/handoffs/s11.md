# S11 handoff — the default switch

**Status:** delivered in [PR #138](https://github.com/ljawor/STAR-ARMADA/pull/138) on
`feat/s11-default-authored`; merge, tag and release still need their own authorization. Engine `0.16.0`. Decision `s11-default-switch-2026-10-19`.

## What shipped

- `render/menus.py`: shipped default `model_preview = True`; new `model_preview_explicit` marker;
  `load_settings` migration so a pre-switch `false` is treated as a default rather than a decision;
  the settings row records the marker when the player moves it.
- `render/asset_selection.py`: `diagnostics()['coverage']` (`ok`, `required_core_failures`,
  `authored`, `procedural`), computed once per selection generation, plus a logged error when a
  required core binding fails to load.
- `tools/art/build_release_asset_lock.py` + `art/manifests/release-asset-lock.json`: 103 required
  bindings, 21,126,346 payload bytes, every pin verified against disk; `--check` is the drift gate.
- `tests/test_s11_default_switch.py`: default, migration, explicit-rollback, completeness and
  rollback-rehearsal coverage; `tests/test_asset_selection.py` updated where it asserted the old
  default.
- `docs/BLENDER_MODEL_S11_PLAN.md`, `docs/MODEL_PREVIEW.md`, `docs/VISUAL_MODEL_PACKS.md`.
- Version `0.15.1` → `0.16.0`.

## Evidence

Frozen macOS package from this branch (422 files, 139.6 MB, 103/103 payload hashes): fresh,
pre-switch-upgrade and explicit-legacy smokes all exit 0; fresh vs upgraded **0.055 %** of pixels
differ, fresh vs legacy **2.774 %**. `validate-models --all` 1034/1034, `sync_runtime_metadata
--check` 112 files, lock `--check` OK, focused union 24 tests OK.

**Test verdict** (final commit, `tools/acceptance/run_suite_per_module.py`): 211 modules, 2,292
tests, **209 pass / 2 fail**, 4,117 s. The two are the pre-existing `test_gl_lifecycle` and
`test_crew_recovery_ui` fixtures, proven on `main`'s bytes in PR #137's control.

- 60/30 FPS reference **unmet** by the authored catalogue (and by legacy alone); optimisation is a

  revision and is deliberately not mixed into the switch.
