# Imperial Visual Prototypes

## 1. Current status and authority

All six original designs below are owner-approved for appearance. The owner authorized committing, publishing and merging them through PR #141 and explicitly waived CI for that PR only. The exact wording, reviewed revision, six asset hashes and scope are recorded in `artifacts/imperial-flight-prototypes/OWNER_REVIEW.json`.

This record supersedes historical “pending review”, “unapproved” and “local only” notes in the capture READMEs and prototype SOURCE files. Those files describe their capture/iteration stage; the original evidence and approved source bytes are preserved. The manifests remain experimental visual-pack manifests rather than core-catalogue approval/activation records.

## 3. Play from the source checkout

Run any repository launcher on macOS after the normal project `.venv` setup:

- `Play Vigil Prototype.command`
- `Play Imperium Command Center.command`
- `Play Imperial Shipyard.command`
- `Play Imperial Mining Station.command`
- `Play Talon Interceptor Squadron.command`
- `Play Engineering Corps Corvette.command`

Each enables all six packs and frames/selects the named subject in the real game. Local Desktop wrappers point to these launchers but are not shipped repository files. The installed application bundle is not replaced or rebuilt by this PR.

The isolated playtest profile is `~/Library/Application Support/STAR ARMADA/Vigil Prototype/`. Normal application settings, saves and replays are separate. The Mining Station review focus adds one prebuilt mine to a disposable copy of the map for immediate inspection; the other launchers use the stock starting fleet. This is not proof of organic mining-site construction. Talon retains the existing representative-fighter rendering and six-member gameplay squadron.

## 5. Verification and CI waiver

The bounded local integration command is:

```sh
PYTHONPATH=tests .venv/bin/python -m unittest test_vigil_prototype test_command_prototype test_industry_prototypes test_flight_prototypes -v
```

Seven focused tests passed before publication, and real-game launches accepted all six packs. Real-driver capture comparisons used 4× MSAA, matching cameras, unchanged simulation digests and stable nominal sizes. Normal existing user-file hashes were unchanged. These checks do not constitute a full suite, native Windows graphics acceptance, packaging acceptance or a fleet-performance claim.

CI is intentionally skipped for this PR at the owner's request using commit-message skip markers on the final branch commit and squash merge. No workflow file or repository-wide CI setting is changed. Older-head checks are historical evidence, not a passing result for the waived final head.

## 6. Not included

No production/default activation, approved core asset replacement, engine version bump, tag, app installer, release or wider catalogue rollout. Those are separate scope decisions; merging these reviewed original prototypes does not silently perform them.
